# PhotoKeywordsWechatMiniProgram

微信小程序体验版，用于小范围体验「日常修图关键词完善器」。

这是 `PhotoEditingKeywords` 静态站点的微信小程序版本：不接 AI API、不上传图片、不生成图片，只在小程序端用离线规则把一句修图想法整理成可复制的提示词。

## 使用方式

1. 用微信开发者工具打开本目录。
2. 将 `project.config.json` 里的 `appid` 替换成你自己的小程序 AppID。
3. 在开发者工具里预览，确认三步流程：选方向、写想法、复制结果。
4. 上传体验版，再添加体验成员。

## 当前能力

- 支持人像、日常、胶片、手账、旅行、小物、清理背景、涂鸦快照风等方向。
- 支持“智能拆解并覆盖填充”和“只补空项”。
- 高级字段默认折叠，可继续细调主体、场景、光线、色彩、注解、禁止项和底部安全留白。
- 输出完整提示词、分层关键词、一句话压缩版和 JSON 结构化版本。
